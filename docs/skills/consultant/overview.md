# Консультант: обзор

Статус: проект пользовательского Overview на согласование, 2026-09-08.
Документ создан по прямому поручению пользователя; утверждение и реализация
ещё не выполнены.

## Что это

Консультант — поставляемый в плагине Issue Grinder субагент на Astra,
к которому другая модель может обратиться за помощью с действительно сложной
проблемой. Он изучает вопрос и объясняет, как разумно продолжить работу.

Краткое описание для обнаружения: «Если ты не Astra и столкнулся со сложной
проблемой, для которой нужна более сильная консультация, обратись к
Консультанту. Это дорогой read-only советчик: передавай конкретный вопрос и
существенные факты, когда ожидаемая польза оправдывает стоимость».

## Для кого и зачем

Консультант предназначен для агентов, работающих со skills плагина Issue
Grinder. Он позволяет привлекать возможности Astra к трудным решениям,
сохраняя основную работу за более дешёвой моделью.

Его результат — обоснованная рекомендация, которая помогает преодолеть
затруднение, избежать ошибочного направления или выбрать способ проверки.
Исполнение и ответственность за итог остаются у обратившегося агента.

## Ожидаемая польза

Короткое обращение к сильной модели может оказаться выгоднее длительного
перебора неудачных решений. Экономия является проверяемой гипотезой:
важна стоимость всей решённой задачи с учётом консультации и последующей
проверки, а не только длина ответа советчика.

Конкретные обязательные свойства предложены в [Requirements](requirements.md).
