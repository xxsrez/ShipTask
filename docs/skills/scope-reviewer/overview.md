# Scope Reviewer: обзор

Статус: действующий пользовательский Overview, 2026-09-02.

Этот документ определяет общий смысл Scope Reviewer: что это за сущность, для
кого она существует и зачем мы её разрабатываем. Он принадлежит пользователю и
меняется только по его явному указанию. Конкретные обязательные свойства
находятся в [Requirements](requirements.md), а способ их достижения — в
[Architecture](architecture.md).

## Что это

Scope Reviewer — skill, который превращает распределённый по Task Manager план
или ход Release в целостную и понятную человеку картину. Он позволяет увидеть,
что именно предстоит сделать, какое состояние есть сейчас, к какому результату
ведёт работа, где находятся существенные риски и требуется ли участие человека.

Это не ещё один список Tasks и не техническая сводка работы агентов. Scope
Reviewer глубоко анализирует выбранный scope с нескольких уместных точек зрения,
отбирает только значимые выводы и собирает из них один лёгкий для чтения отчёт.

До начала исполнения Scope Reviewer также помогает улучшить сам план. Он может
автоматически исправлять изменяемую агентом часть planning model, но сохраняет
согласованные человеком Requirements неприкосновенными и выносит обнаруженные в
них вопросы на обсуждение.

## Для кого он существует

Skill предназначен для человека, который определяет требования и следит за
продуктом или проектом, но не должен ради контроля погружаться во все карточки,
технические детали и внутреннюю работу агентов.

Пользователь должен получать достаточную картину для содержательного решения:
понимать общий замысел, будущий результат, текущее продвижение, спорные места и
необходимые точки контроля, не восстанавливая всё это самостоятельно из
разрозненного task graph.

## Какую пользу он даёт

Scope Reviewer связывает планирование, согласование и исполнение в один
прозрачный цикл:

- после создания плана показывает понятный обзор будущей работы;
- находит и автоматически исправляет проблемы в изменяемой части плана;
- отдельно показывает противоречия, пробелы и вопросы в человеческих
  Requirements;
- после согласования Requirements повторно проверяет обновлённый план и помогает
  понять, готов ли он к исполнению;
- во время Release даёт такой же понятный обзор текущего состояния, оставшейся
  работы, рисков, препятствий и ожидаемых действий.

Коротко: Scope Reviewer даёт человеку visibility на весь выбранный scope и
помогает довести план до состояния, в котором его можно осознанно передать в
исполнение.
